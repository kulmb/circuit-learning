Fig. 01 · System map

同一份内核，两种运行时

共享内核分别编译进浏览器和 API，不经过网络。工作台用它在本地点亮灯泡；服务端用同一套关卡与计分规则， 校验关卡状态、重算星星，并把进度写进 MongoDB。

Fig. 02 · Write path

一次通关，如何落库

进度写入不依赖网络在线。客户端先完成判定，再把尝试放进仓库；断网时排队，恢复后重放。 服务端只管最后一步：校验、重算、事务。

Shared kernel

规则只写一遍

@circuits/shared 不依赖 React、DOM 或 Node。它既是电路求解器，也是关卡、计分和 API 契约的单一来源。

SIMULATION

电路引擎

MNA 节点分析 + 高斯消元与部分主元；LED 用最多 12 次迭代收敛。 输出 off / dim / normal / bright 四档状态、每根导线的有向电流，以及短路、断路、反接等诊断。

LEVELS

关卡定义

第一章「光」有 10 个关卡和 1 个符号过渡。关卡分 circuit / materials / matching 三类， 成功条件、提示和词汇都通过文本 ID 引用，不把法语写死在逻辑里。

PROGRESSION

进度规则

starsForHints 决定星星，成功解锁下一关，applyAttempt 统一合并尝试。 前端即时反馈，服务端用同一套规则重算，避免两套计分逻辑漂移。

CONTRACTS

zod 契约

请求、响应和 DTO 都用 zod 描述；电路 JSON 带版本号，可序列化、可回放。 API 输出从不携带 _id、__v 或密码哈希。

关键边界：共享的是代码和规则，不是数据库。浏览器永远拿不到 Mongoose 模型；星星与解锁由 API 重算入账。

Client

把反馈留在手指边

孩子每拖一下、每接一根线，工作台都要立刻回应。网络可以慢，灯泡不能等。

WORKBENCH

SVG 工作台

组件、导线和端子全部是 SVG。交互只走 Pointer Events，鼠标、手指和触控笔共用一套逻辑； 磁吸网格、两次点按接线、拖进垃圾桶删除、50 步撤销。

写实、符号、并排三种显示模式，让孩子从真实元件逐步过渡到标准符号。

PROGRESS

离线优先的仓库

ProgressRepository 有两个实现：访客写 localStorage，学生走 API。 网络失败时操作进入本地队列，恢复后按顺序重放。

访客进度可以合并到账号；确定性 attemptId 让中断的合并不会产生重复记录。

SCREENS & SOUND

屏幕、字号与声音

ResizeObserver 按真实宽高选择 compact / medium / large，不看设备类型。 Nunito 字体自托管，按钮最小 48 px，紧凑模式 56 px。

旁白优先播放 MP3，缺失时回退 Web Speech API；首次触摸解锁音频。

PWA

离线也要能玩

Workbox 预缓存应用、字体、图标、音频和关卡模块。导航回退到 index.html， 已加载的关卡断网也能打开。

API 走 NetworkFirst，但只有 Cache-Control: public 的响应能进缓存；个人数据统一 no-store。

体积预算：首屏 JS 约 125 KB gzip；管理后台、游戏壳和完整关卡定义都按需加载。

Server & data

权威状态放在服务端

Fastify 负责身份、权限、校验和事务。Mongoose 模型严格，输出经过 DTO；孩子只留下昵称、头像、群组和进度。

IDENTITY

两种登录，两种节奏

成人用短用户名 + argon2id 密码，30 天滑动会话；连续失败会锁定，认证路由有限流。

孩子用 6 位群组码 + 3 张有序图片；会话固定 8 小时。设备固定 Cookie 记住群组 30 天，免去每次输码。

AUTHORITY

进度由服务端重算

关卡必须存在且已解锁；星星按提示数重算；尝试、进度、解锁和词汇在同一个事务里完成。 $inc、$max、$min 合并统计，客户端 ID 保证幂等。

HARDENING

默认防护

Cookie 为 httpOnly · SameSite=Lax · Secure；会话与邀请令牌只存 SHA-256；TTL 索引自动过期。

zod 校验所有输入，sanitizeFilter 防 NoSQL 注入，Mongoose 严格模式拒绝未知字段。

PRIVACY

儿童数据最小化

学生没有邮箱、姓氏、生日或成人密码。学生数据可以导出 JSON，也可以在事务中彻底删除该学生及其进度、尝试、沙盒和会话。

站点无第三方分析、无外部 CDN，管理操作写入审计日志。

集合 存什么 关键约束
users角色、显示名、成人凭据、头像、家长关系、词汇学生无邮箱与密码
groups名称、6 位群组码、成员及组内角色群组码唯一

MongoDB 以单节点 replica set rs0 运行，因此事务在开发和测试环境都真实可用。 索引由启动时的 syncIndexes() 和 migrate-mongo 迁移两条幂等路径共同维护。

Fig. 03 · Deployment

一台主机，两套隔离环境

生产与开发共用 OCI Ampere A1 主机，但域名、端口、静态目录、Compose 项目和数据库卷完全分开。 Caddy 在宿主机上，负责 TLS、CSP 和路由。

Quality gates

四道闸门

电路引擎、事务、触控尺寸和儿童文案都有自动化或审计兜底。测试不只覆盖“能跑”，也覆盖“孩子能用”。

单元测试

Vitest 覆盖共享引擎的串联、并联、短路、LED、材料和序列化，以及 API 服务与前端组件。

真实事务

mongodb-memory-server 启动单节点 replica set，测试和 E2E 都使用真实事务与索引。

设备端 E2E

Playwright 覆盖 7 种设备配置、视觉快照、离线、权限、沙盒以及家长 / 教师 / 学生流程。

儿童可用性

12 词句子测试、法语 Hunspell 检查、48 / 56 px 触控目标审计，以及首屏体积预算。

Trade-offs

四个明确取舍

这些选择决定了系统的形状：共享规则、离线优先、单一交互模型、隐私默认。

共享内核，而不是复制规则

客户端和服务端跑同一份 TypeScript。代价是包必须保持纯粹；收益是灯泡亮度和星星规则永远不会分叉。

离线优先，而不是失败重试

进度仓库自带缓存和队列，网络只是其中一种传输方式。代价是幂等设计必须从第一天就做对。

触摸优先的单一交互模型

只用 Pointer Events，不依赖悬停、双击或键盘。代价是少量桌面便利；收益是 iPad、Android 和鼠标共用一套逻辑。

隐私默认，不靠配置

无第三方分析、无外部 CDN、个人数据不进入 Service Worker 缓存。孩子只留下完成游戏所需的最少信息。
